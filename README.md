# 들꽃교회 홈페이지 · 소식지 업로드 안내

## 처음 한 번: 홈페이지 게시
1. 목사님 GitHub 계정으로 로그인해 공개 저장소를 만들고 이 폴더 **안의 모든 파일 및 숨김 폴더 `.github`까지** 저장소 최상위에 올립니다. ZIP 자체를 올리지 마세요.
2. GitHub 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
3. **Settings → Actions → General → Workflow permissions → Read and write permissions → Save**. (설정이 보이지 않거나 제한되어 있다면 저장소 관리자 권한 확인)
4. **Actions** 탭에서 작업이 실행 가능한지 확인합니다.

## 매주: 목사님이 소식지 올리는 방법
1. GitHub에 목사님 계정으로 로그인합니다.
2. 홈페이지 저장소를 열고 `bulletins` 폴더를 누릅니다.
3. **Add file → Upload files**를 누릅니다.
4. PDF 또는 JPG/PNG/WebP 파일을 선택합니다. 예: `2026-10-25_들꽃교회_주보.pdf`.
5. 아래 **Commit changes**를 누릅니다.
6. 약 1~3분 후 **Actions → 소식지 목록 자동 갱신** 실행 결과를 확인합니다. 완료되면 홈페이지 **교회 소식지** 메뉴에 자동 표시됩니다. GitHub Pages 배포 지연이 추가로 발생할 수 있습니다.

## 권한과 주의사항
- 방문자는 소식지를 읽을 수만 있고 홈페이지에 업로드 버튼은 없습니다.
- **목사님만 업로드**하려면 저장소를 목사님 계정이 소유하고, 다른 사람에게 쓰기 권한을 주지 않아야 합니다. GitHub 저장소 소유자 및 쓰기 권한이 있는 협업자는 업로드할 수 있습니다.
- 공개 저장소의 소식지에는 개인 전화번호, 민감한 개인정보 등을 싣지 마세요.
- 파일이 올라가도 목록이 보이지 않으면 Actions 실행 상태와 Workflow permissions를 확인하세요.
- GitHub Pages에서는 서버에 직접 파일을 업로드할 수 없으므로 목사님은 GitHub 화면에서 파일을 등록합니다.


## 교회 주소
경기도 하남시 신평로 12, 삼보빌딩 3층. 홈페이지의 네이버 지도 버튼은 이 주소를 검색합니다.
